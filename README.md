# -空气质量监测分析
## 本案例是10 万条级别的大数据量案例，通过城市空气质量监测数据分析的环保业务场景，帮助你练习大数据量下的四大工具协同使用，完全避开传统业务场景，贴近真实的智慧城市环保业务。
•	MySQL：练习大数据量的存储、批量写入、高效查询，处理 10 万条监测数据的数据库操作
•	NumPy：练习大数据量下的向量化数值计算、批量指标换算、高效统计，比循环快 100 倍的向量化运算
•	Pandas：练习大数据量的数据清洗、缺失值处理、分组聚合、时间维度分析，高效处理 10 万行数据
•	Matplotlib：练习大数据量的可视化优化、采样绘制、聚合后绘图，避免大数据量下的图表卡顿
